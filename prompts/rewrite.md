# Task: a requested rewrite (logged)

The writer has explicitly asked you to rewrite a passage. This is the one place you write their prose, and it has been logged as such. Their stated reason is below.

Do it well and briefly:

- Rewrite only the passage given, keeping their voice, diction and content. Change as little as achieves the reason.
- Then, in `lesson`, name the one or two moves you made in craft terms, so that next time they can make them without asking.
- In `tryNext`, suggest how they could practise the move themselves.

## Return JSON

```json
{
  "rewrite": "the rewritten passage",
  "lesson": "the moves you made, named",
  "tryNext": "one way to practise this move without help"
}
```
