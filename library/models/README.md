# Model passages

Public-domain passages for the Imitation studio. One file per passage: a short frontmatter block (author, title, year, genre, tags) and the text.

Add your own by dropping in another `.md` file in the same shape. These were transcribed for the app; check them against a source edition (Project Gutenberg, the Library of America) before treating any as authoritative — the exercises work best on an exact text.
